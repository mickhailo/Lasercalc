⚙ Потрібно підключити Firebase
Ще один крок — і авторизація та дані працюватимуть на будь-якому пристрої.
1. Зайди на console.firebase.google.com і створи проєкт (безкоштовно, потрібен лише Google-акаунт).
2. Build → Authentication → Get started → Sign-in method → увімкни Email/Password.
3. Build → Firestore Database → Create database → обери регіон (найближчий) → почни в production mode.
4. У Firestore → вкладка Rules → встав правила (я дав їх окремо) → Publish.
5. Шестерня (Project settings) → внизу Your apps → іконка </> (Web) → зареєструй застосунок → скопіюй об'єкт firebaseConfig.
6. Встав його у файл замість "ВСТАВ_СЮДИ" (на самому початку HTML-файлу) і збережи файл.
7. Онови цю сторінку.
